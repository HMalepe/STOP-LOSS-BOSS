## Gotchas I learned
- `db.tx()` on a Db that is already a transaction JOINS it (no new connection). That's what makes `audit(t, …)` atomic
  with the change. Don't "fix" it into a savepoint without a reason.
- `audit()` takes a key now: `audit(db, auditKey(sessionSecret), entry, at)`. `verifyChain(db, key)` too.
- The TOTP ciphertext is AAD-bound to the user id: use `openTotpSecret(sealed, userId, secret)`, never raw `decrypt`.
  Old mock databases from before 27d4cb5 need `pnpm seed:owner --replace` (or delete `.data/`).
- Any throttled auth step must call `reserve()` BEFORE verifying anything. Checking first and recording after is the bug
  the review found.
- Handlers get `ip` from the guard (`RouteContext.ip`), read from `TRUSTED_IP_HEADER` only. Never call `clientIp` with a
  different header in a route.
- Two logins in the same 30 s TOTP step: the second is a replay and is refused. Tests advance the clock 30 s between.
- `pnpm seed:owner` reads stdin via readline: it needs a real terminal (piped input is swallowed).
- Mock mode with no APP_ORIGIN accepts POSTs only on loopback. Testing from a phone on the LAN needs APP_ORIGIN set.
