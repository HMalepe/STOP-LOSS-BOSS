## Gotchas I learned
- Virtual time: anything the code awaits must go through the injected scheduler; a real setTimeout in a test is invisible to it.
- A zombie's in-flight slot must be kept, not released-then-re-held: the gap lets another request in (caught by a test).
- `pnpm fix` (format → lint-fix → format) before verify saves a cycle every time.
- Check verify's exit code directly; never through a pipe.
