## Gotchas I learned
- **Never chain `pnpm verify | grep … && git commit`**: the pipe hides verify's exit code. Run verify to a log, check `$?`, then commit.
- MetaApi `profit` EXCLUDES swap and commission on the open part. Use unrealizedProfit + unrealizedSwap + unrealizedCommission.
- The SDK holds a trade until it has a connected instance, with no timeout: our timeout doesn't cancel it. Always handle `settled`.
- The SDK's "import" export condition is its browser build: load it with createRequire.
- Prettier reflows lines; scripted edits must match the formatted text (or use the Edit tool after reading).
- Fake timers + jittered backoff: pin `random` in tests, and always restore real timers in afterEach.
