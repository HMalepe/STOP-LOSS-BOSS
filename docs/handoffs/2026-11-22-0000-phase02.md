## Gotchas I learned
- Prettier reflows test lines: scripted find/replace on tests must match the formatted text.
- `1.1 + 0.2 === 1.3` is actually true in IEEE floats. Use `0.1 + 0.2` or `1.0861 + 0.0011` for float-trap tests.
- Fuzzing found a bug the reviewer missed: a "positive" broker SL can be 0 points on the grid. Keep the fuzz test in the suite.
- `decideModify` has an invariant that every emitted level is > 0. If it ever throws in production, upstream validation has a hole.
